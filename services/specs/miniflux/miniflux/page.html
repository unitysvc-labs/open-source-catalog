Keyboard Shortcuts

Sections Navigation

  • Go to unread = g + u
  • Go to starred = g + b
  • Go to history = g + h
  • Go to feeds = g + f
  • Go to categories = g + c
  • Go to settings = g + s
  • Show keyboard shortcuts = ?
  • Add feed = +

Items Navigation

  • Go to previous item = p, k, ⏴
  • Go to next item = n, j, ⏵
  • Go to feed = F
  • Go to top item = g + g
  • Go to bottom item = G

Pages Navigation

  • Go to previous page = h
  • Go to next page = l

Actions

  • Open selected item = o, Enter
  • Open original link = v
  • Open original link in current tab = V
  • Open comments link = c
  • Open comments link in current tab = C
  • Toggle read/unread, focus next = m
  • Toggle read/unread, focus previous = M
  • Mark current page as read = A
  • Download original content = d
  • Toggle starred = f
  • Save entry = s
  • Toggle open/close entry attachments = a
  • Scroll item to top = z + t
  • Refresh all feeds in the background = R
  • Remove this feed = #
  • Set focus on search form = /
  • Close modal dialog = Esc
